## 3. 問答題

### 問題一：為什麼 "4" 要先轉成數字，才能用於本題的分攤計算？
**回答**：
因為 `"4"` 在 Python 中屬於字串（`str`）型別。如果直接將總金額除以字串（例如 `1220 / "4"`），Python 會引發 `TypeError` 錯誤，因為字串無法直接參與數學除法運算。因此必須先透過 `int("4")` 將其轉換成整數（`int`）或浮點數（`float`），才能正確進行數學除法計算每人費用。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
**回答**：
* **計算過程**：
  1. 先扣折價券：$1,200 - 100 = 1,100$ 元。
  2. 再算 10% 服務費：$1,100 \times 0.10 = 110$ 元。
  3. 應付總額：$1,100 + 110 = 1,210$ 元（若後續扣除折價券則是直接用 $1,100 + 110 = 1,210$）。
* **與規定的不同原因**：
  餐廳或商家計算服務費的實務慣例，通常是以原本的餐點總消費額為基礎來計算 10% 服務費，折價券則是商家給予的折扣優惠（相當於現金抵用）。如果先扣折價券再算服務費，會導致服務費的基底變小（從 1,200 變成 1,100），使服務費金額變少（從 120 變 110），這不符合多數餐廳「以原始餐費計收服務費」的商業邏輯與本題規定。
